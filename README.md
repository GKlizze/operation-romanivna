# Операція: Романівна

Персоналізована романтична мінігра для Дарини Романівни: сім рівнів, які непомітно збирають її побажання щодо спільного часу і перетворюють планування побачення на маленьку пригоду.

Стек: React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · Framer Motion · Lucide Icons · Vitest.

## Як це працює

| Рівень | Механіка | Що зберігається |
| --- | --- | --- |
| 1. Який у нас сьогодні вайб? | квіз з одним варіантом і жартівливою реакцією | `vibe` |
| 2. Склади наше ідеальне меню | конструктор меню з віртуальним столиком | `menu` |
| 3. Піймай поцілунок | сердечка в кризі: розбий кригу, поки зубки не дісталися, 15 секунд | `kisses`, `bites` |
| 4. Або-або | 5 раундів по 5 секунд, без штрафу за таймаут | `eitherOr` |
| 5. Таємний конверт | три конверти з перемішаними нагородами, купон у PNG | `coupon` |
| 6. Карта спокус | розподіл рівно 10 годин між 5 категоріями | `hours` |
| 7. Останнє запитання | вільна текстова відповідь | `wish` |

Фінальний екран динамічно формує сценарій побачення з усіх відповідей, дозволяє зберегти картку як PNG, поділитися результатом і почати заново.

Прогрес зберігається в `localStorage`, тож оновлення сторінки нічого не ламає, а кнопка «назад» повертає на попередній рівень без втрати відповідей.

## Як організатор отримує відповіді

`localStorage` на телефоні Дарини не синхронізується з вашим пристроєм, тому є два канали:

1. **Поділитися результатом (працює одразу).** На фінальному екрані кнопка «Поділитися результатом» відкриває системне меню поширення з посиланням виду `…/admin?r=<стислий результат>`. Коли Дарина надішле його вам у месенджер, відкрийте посилання, введіть пароль організатора і побачите всі відповіді та сформований план. Той самий код можна вставити вручну на сторінці `/admin`.
2. **Серверний API (необов'язково).** Якщо задати змінні `SUBMIT_URL` та `RESULTS_URL` (GitHub → Settings → Secrets and variables → Actions → Variables), гра після завершення автоматично відправить результат `POST`-запитом, а `/admin` зможе підтягнути список результатів. Найпростіший безкоштовний бекенд — Google Apps Script, прив'язаний до Google-таблиці:

```js
const SHEET_ID = 'ID_вашої_таблиці'

function doPost(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0]
  const body = JSON.parse(e.postData.contents)
  sheet.appendRow([new Date().toISOString(), JSON.stringify(body.result)])
  return ContentService.createTextOutput('ok')
}

function doGet() {
  const rows = SpreadsheetApp.openById(SHEET_ID).getSheets()[0].getDataRange().getValues()
  const out = rows.map((r) => ({ sentAt: r[0], result: JSON.parse(r[1]) }))
  return ContentService.createTextOutput(JSON.stringify(out)).setMimeType(ContentService.MimeType.JSON)
}
```

Опублікуйте скрипт як веб-застосунок («Доступ: усі»), і його URL використайте як `SUBMIT_URL` та `RESULTS_URL`.

## Сторінка організатора `/admin`

Захищена паролем. У коді зберігається лише SHA-256 пароля (змінна `VITE_ADMIN_PASSWORD_HASH`), сам пароль — ні. На сторінці видно всі відповіді, кількість поцілунків, купон, розподіл годин, бажання, сформований план, а також є експорт у JSON.

Щоб змінити пароль:

```bash
printf '%s' 'НовийПароль' | shasum -a 256
```

Отриманий хеш запишіть у секрет `ADMIN_PASSWORD_HASH` репозиторію (GitHub → Settings → Secrets and variables → Actions) і перезапустіть workflow. Локально хеш береться з `.env.local`.

## Деплой

Будь-який пуш у `main` збирає проєкт і публікує його на GitHub Pages через `.github/workflows/deploy.yml`. Шлях `/admin` працює завдяки копії `index.html` у `404.html`.
